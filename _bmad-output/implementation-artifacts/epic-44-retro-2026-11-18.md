## Process lessons

1. **T0 trace trong spec-writing trả cổ tức lớn nhất epic** — architect A5 nghi commit-gap → task bắt buộc trace → bug prod thật. Pattern: spec chứa "phải chứng minh/truy vết trước khi code" > "implement theo spec".
2. **Parallel worktree agents lần đầu sạch** (44.2 ∥ 44.4): conflict chỉ 2 file (import union + test-summary). Khác Epic 43 vì (a) spec đã pin file-ownership per story, (b) verbatim git-proof gate, (c) coordinator verify repo trước khi tin report.
3. **5 vòng review skeleton = 0 spec-surprise khi build** — mọi deviation đều nhỏ và named; không phải re-plan giữa chừng.
4. **Spec-hedge cần "latest-state pass" trước dispatch** — spec-44-3 viết "nếu file chưa tồn tại thì tạo" nhưng `campaign_tasks.py` đã có khi 44.2 merge trước → phải gửi correction kèm dispatch. Lesson: re-verify anchors ngay trước launch agent.
