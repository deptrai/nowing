## 4. Findings

### 4.1 Aggregate views

- **Scope creep / overlap:** `nowing_backend/app/reports/narrative/` thuộc Story 6.12 (Narrative Report Engine) — nằm ngoài Epic 5 nhưng dựa trên nền tảng report có sẵn. Điều này cho thấy Epic 5 là **khởi nguồn** của khái niệm deliverable, sau đó được mở rộng trong Epic 6.11/6.12 (vertical alert rules + narrative reports).
- **Architecture:** Podcast lifecycle service có state machine rõ ràng (`PENDING → AWAITING_BRIEF → DRAFTING → RENDERING → READY`). `PodcastError` hierarchy tách preconditions, transitions, và conflicts.
- **God-class watch:** `image_generation_routes.py` (561 dòng) khá lớn; nên xem xét tách validation/parsing ra schema layer.
- **Pattern consistency:** Image gen dùng `ImageGenRouterService` để chọn provider và model theo workspace config; podcast dùng `TTSFactory`; report dùng `NarrativeSynthesisEngine`. Cả ba đều có abstraction layer cho media generation.

### 4.2 Test coverage

- Podcasts có test integration khá đầy đủ (12 files) bao gồm streaming, scoping, regeneration, brief gate, cancel, voice preview.
- Reports có test engine + routes.
- Image generation có unit tests cho quota, API base defense, safety net, image support.
- Không thấy e2e test cho video deliverable (nếu có) — podcast có `render` task nhưng không rõ test video output.
