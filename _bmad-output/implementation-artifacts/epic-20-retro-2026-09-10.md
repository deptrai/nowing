## 4. Findings

### 4.1 Aggregate views

- **Service auth:** `ChainLensServiceAuth` thay thế `auth_stub`, hỗ trợ multi-token env var, JWT expiry rotation (<30 ngày), correlation/workspace headers, HMAC `x-user-ctx` fast-path.
- **Chunk normalization:** `to_chunks`/`serializer` cho job/listing/news/stock domains; stable `sourceId`, PII redaction, >8000 token splitting, schema validation.
- **Ingest pipeline:** `NowingIngestService` gọi `POST /v1/ingest/scraper` với retry, parent/child job tracking, 409→noop, dead-letter queue.
- **Gap-fill:** `POST /v1/gap-fill` với scraper callback `POST /v1/scraper/{id}/run`, async mode qua `run_id` SSE.
- **Private provider:** `NowingPrivateProvider` cho `POST /v1/private-data/search`, workspace RLS, connector scoping, không leak chunks khi auth fail.

### 4.2 Diff-scope review

- **20.1** — Chunk schema + ingest service + retries/validation.
- **20.2** — Gap-fill orchestrator + internal scraper callback + cost split.
- **20.3** — Private provider route + RLS + cost metering.
- **20.4** — Service auth + cost ledger sync + token rotation.
