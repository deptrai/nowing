## 4. Findings

### 4.1 Aggregate views

- **Architecture delta:** `nowing_backend/app/automations/` là domain module lớn nhất trong backend (~3,250 LOC). Nó có lớp phân tách rõ: `api/` (routes), `services/` (business logic), `runtime/` (execution), `dispatch/` (input resolution), `templating/` (Jinja sandboxed), `triggers/` (schedule/event/memory_change), `actions/` (builtin + MCP), `persistence/` (models/enums).
- **Pattern consistency:** `AutomationDefinition.inputs` + `Inputs.schema_` (JSON Schema 2020-12) được dùng chung cho cả playbook và action — đúng như architect review (Winston) đã chỉ ra. Không có lớp params thứ hai.
- **God-class watch:** `playbook_service.py` (530 dòng) và `playbook_seed_service.py` (450 dòng) là hai file lớn nhất; `automation.py` service (335 dòng) cũng cần theo dõi.
- **Brownfield overlap:** Stories 6.6/6.7/6.9 không có story files riêng vì chúng là "expose cơ chế đã có" theo architect review — không phải build mới. `epics.md` chứa đầy đủ context và acceptance criteria.

### 4.2 Diff-scope review

- **6.4** — Direct write-back actions (Notion/Slack/Linear/Jira). Code review findings resolved in `d2312df94`. Action registry extended with new `ActionDefinition` types.
- **6.5** — Memory-driven automations. `memory.changed` event + `memory_change` trigger type implemented; best-effort publish không fail memory write.
- **6.6** — Playbook reuse. Expose `inputs.schema` sẵn có thành playbook contract; versioning pin theo version cũ; ownership `workspace` vs `system`.
- **6.7** — Schema-driven form UI. `x-ui` hints trong JSON Schema cho renderer; Pydantic validation trước khi lưu; LLM output không được tin trực tiếp.
- **6.8** — Generic Alert Engine. Một engine duy nhất cho jobs/news/stock/price/company/competitor alerts; reusable scheduler + diff + notification stack.
- **6.9** — Workspace `vertical` + Playbook Library. `vertical` attribute trên workspace; playbook filtered theo vertical; definition + schema (data) only, không cần UI code mới.
- **6.10** — Inbound mail gateway + Stateful Scheduled Tasks 2.0. Email trigger qua `task@nowing.ai`; recurring tasks resume từ checkpoint; code review patches applied (webhook commit, jsonb dump, retry loop, replay check, html sanitization).
- **6.11** — Vertical Alert Rule Templates. Consolidated 14.3/15.3/16.3/17.3/17.4 thành template system trên Generic Alert Engine.
- **6.12** — Narrative Report Engine. Consolidated 14.4/15.4/16.4; synthesis engine với citations, degraded mode khi capability unavailable.
