## 4. Findings

### 4.1 Aggregate views

- **Architecture shift:** Nowing không giữ local canonical index nữa; mọi scrape result được gửi lên `chainlens-research` qua `ingest` service. Điều này giảm local storage burden và tập trung canonicalization về engine.
- **Ingest pipeline:** `ingest.py` (505 dòng) là orchestrator chính. `ingest_reception.py` handle incoming payloads. `auth.py` (366 dòng) đảm bảo HMAC signing giữa Nowing và ChainLens.
- **Gap fill + private provider:** `gap_fill.py` và `private_provider.py` (659 dòng) hỗ trợ ChainLens gap-fill và proxy. Đây là phần tích hợp sâu nhất.
- **Dead code removal:** `542b84d61 refactor: remove Epic 13 canonical entity dead code` — cho thấy local canonical index code đã được dọn dẹp sau khi chuyển sang ChainLens.
- **Health monitoring:** `chainlens_probe.py` theo dõi ChainLens availability.
