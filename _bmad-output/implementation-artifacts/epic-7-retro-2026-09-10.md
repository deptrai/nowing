## 4. Findings

### 4.1 Aggregate views

- **Architecture delta:** MCP server của Nowing mở rộng từ bộ tool lõi thành đầy đủ surface: memory, workspace team memory, image generation, BĐS scrapers, automations, reports. `mcp_tools.py` chứa 42+ tools (theo AC story 7.7). `routes/connectors/mcp.py` 649 dòng là file lớn, đáng xem xét tách handler per tool group.
- **Client surface:** `nowing_web` có `/connectors` page, `workspace-mcp-tools-control`, MCP server marketing page. Các connector journeys E2E bao gồm 10+ integrations.
- **i18n maturity:** `vi.json` thêm vào bộ 6 locale sẵn có (`en`, `es`, `pt`, `hi`, `zh`, `ko`). `test(i18n)` fail khi locale thiếu key so với English — giữ sync đồng bộ.
- **God-class watch:** `nowing_backend/app/routes/connectors/mcp.py` (649 dòng) là file lớn, chứa nhiều tool handlers. Nên theo dõi hoặc tách group handlers nếu tiếp tục mở rộng.

### 4.2 Diff-scope review

- **7.4** — Dedicated connectors layout: full-page dashboard thay cho modal, rail + detail pane, degraded state với cached data, mobile drawer. PR #1624 merged.
- **7.7** — MCP server tool expansion: 11 tool groups thêm vào catalog (TEAM_MEMORY, IMAGE_GENERATION, AUTOMATION, REPORT, BĐS scrapers). `selfcheck` báo cáo 42 tools. Slices 4-5 hoàn thành (chat + automation run). Error handling: `capability_unavailable`, `invalid_response` không crash agent.
- **7.8** — Vietnamese i18n: `vi` locale auto-detect từ browser language hoặc timezone (`Asia/Ho_Chi_Minh`, `Asia/Saigon`, `Asia/Hanoi`), preference lưu `localStorage` không bị override.

### 4.3 Behavior check

- Playwright E2E cho 7.7 automation manual run (`272c6c806`) và workspace MCP tools (`workspace-settings/mcp-tools.spec.ts`).
- i18n test fail-fast khi locale mất sync (`10f6725a5`).
