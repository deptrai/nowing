## 4. Findings

### 4.1 Aggregate views

- **Public API surface:** `agent_chat_routes.py` với PAT auth, rate limit 429, audit log (không lưu message body), thread linkage.
- **Agent registry:** `agent_configs` table + seed `bdsai-listing-assistant`; `AgentConfig` cho phép custom system prompts và tool allowlist/denylist.
- **Tenant isolation:** `client_id`/`agent_id` trên `Memory`, `ResearchThread`, `Run`, `TokenUsage`, `new_chat_threads`; composite RLS policies; tenant GUC `app.current_client_id`.
- **Cost traceability:** `TokenUsage.external_metadata` lưu `listing_id`, `broker_id`, `user_id`.
- **Memory RAG filter:** hard filter `client_id` cho recall, fail-closed khi tenant context thiếu.
