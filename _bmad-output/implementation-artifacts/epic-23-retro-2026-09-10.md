## 4. Findings

### 4.1 Aggregate views

- **23.1:** Async scraper worker pool trên queue `nowing.lead_scrapers`, Redis Stream bounded `MAXLEN ~ 10000`, dual flush (5 leads / 3s), Lua leaky-bucket, circuit breaker Redis.
- **23.2:** Zalo OA webhook HMAC-SHA256, fast ACK < 100ms, ZNS template modal, two-way conversation sync, opt-out keywords, sending window 08:00–21:30.
- **23.3:** VietQR/Napas payout, row lock `SELECT ... FOR UPDATE`, reconciliation-before-retry, HMAC-SHA256 audit signature, 10% TNCN withholding > 2M VND.
- **23.4:** `leads` table 16 hash partitions (`leads_p0..p15`), composite PK `(id, workspace_id)`, RLS `app.current_workspace_id`, Zero publication `publish_via_partition_root`.
