## Dimension 1-2 digest: Jev technical + maturity

### Claims

**Product definition & API shape**
- [Jev is TypeSafe's flagship model and the first "System One model"; you send a `state` plus typed questions and get structured answers — three primitives: **Choice** (option from a defined set → `choice`, per-option `probabilities`, `confidence`), **Score** (rating against ordered rubric levels → `score`, level probabilities, `confidence`), and **Noul** (yes/no → `noul` 0–1 probability). All three question types can be mixed in one API call; every question is evaluated "in parallel and in isolation" against the same state, and adding questions barely changes response time] — TypeSafe AI official docs (docs.typesafe.ai/introduction, /concepts/system-one), undated (live site), accessed 2026-09-21, confidence: high, class: technical
- [Endpoint is `POST https://api.typesafe.ai/v1/systemone` with Bearer auth; sample response returns `{"model": "jev-1.13.0", "answers": {"department": {"type": "choice", "choice": "technical", "confidence": 0.78, "probabilities": {...}}}}`] — TypeSafe AI docs Quick start, accessed 2026-09-21, confidence: high, class: version
- [Current model is **Jev 1.13** (`jev-1.13.0`), aliases `jev-latest`/`jev-preview` (currently pointing to the same build); context is 64k tokens per request (state + all questions), with 32k for state plus the single longest question; input is **text only** — strings, JSON objects, arrays of text; no image/audio/video "yet". Confidence/probabilities are group-level: "Calibration is measured across groups of predictions; it does not guarantee that an individual answer is correct"] — TypeSafe AI docs (/concepts/system-one, /models), accessed 2026-09-21, confidence: high, class: version
- [Jev is not fine-tuned or LoRA-adapted per customer; not trained on customer requests/responses; ZDR available for enterprise] — TypeSafe AI docs /models, accessed 2026-09-21, confidence: high, class: technical

**RLCD vs RLHF**
- [TypeSafe frames three post-training approaches: RLHF (human preference → chat), RLVR (verifiable rewards → reasoning), and their new **RLCD = Reinforcement Learning for Calibrated Decisions** (decisions + calibrated probabilities instead of generated text). Docs claim: "Outcomes assigned a probability of 0.2 should occur about 20% of the time", explicitly group-level, not per-answer] — TypeSafe AI docs AI primer (/introduction/machine-learning-primer), accessed 2026-09-21, confidence: high, class: technical
- [Docs claim RLHF "was co-invented by Diogo Almeida, cofounder of TypeSafe" with a Google Scholar citation link] — TypeSafe AI docs AI primer, accessed 2026-09-21, confidence: medium (self-claimed credential), class: company
- [An HN commenter (self-described waitlist admit) explains RLCD mechanics as "you basically massively negatively reward a distribution that is {yes: 0.9, no: 0.1} if the answer was no, and less negatively reward a {yes: 0.6, no: 0.4}" — noting it is "a known existing thing variously called 'calibrated RL'" and that the RLCD acronym now has 3 unrelated expansions] — HN commenter porridgeraisin in launch thread (news.ycombinator.com item 49717558), 2026-09-15/16, accessed 2026-09-21, confidence: low-medium (anonymous technical comment), class: technical

**Determinism / consistency**
- [Jev is **not deterministic**. TypeSafe's own self-consistency cookbook (15 repeats per condition) found TypeSafe's plurality labels repeat 90.8% of the time (vs 87.5–100% for LLMs at temp 0 / default) and "TypeSafe flips on 2 of the 8 questions"; with a confidence gate (top probability ≥ 0.60, else "uncertain" → human review) agreement rises to 99.2%. No temperature parameter is documented for the TypeSafe API; a `uid` field is passed per call] — TypeSafe AI docs consistency cookbooks (llms-full), accessed 2026-09-21, confidence: high, class: technical

### Summary
Jev is real, launched 2026-09-15 in early access with a launch HN thread at 1929 points, and the headline claims check out against the vendor's own docs: $42/Btok input ($0.042/Mtok), free output tokens, 70–500ms latency, typed Choice/Score/Noul answers with probabilities and confidence, model jev-1.13.0, 64k context, text-only. The technology narrative (RLCD, non-autoregressive parallel sampling, "no hallucinations") is entirely self-reported with no paper, no parameter count, no public benchmarks, and credible independent pushback on both the baseline methodology (LLMs forced through TypeSafe's own JSON wrapper) and the "0% hallucination" framing (schema-match guarantee, not correctness); one skeptic argues the moat may be thin since prefill-plus-one-token on ordinary LLMs reproduces much of it, and a March 2025 open-source prior-art claim exists. Company-wise it is a seed-stage San Francisco startup led by ex-OpenAI/Google Brain RLHF researcher Diogo Almeida (co-founders Erik Gafni and Sasha Sheng per one secondary source), with no disclosed funding round — but with an unusually fast and large open-source ecosystem forming within a week of launch.
