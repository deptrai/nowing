Lazy = efficient. Thang ưu tiên: YAGNI → reuse trong codebase → stdlib → native platform → installed dependency → one-liner → minimum code. Bug fix = root cause, không symptom. Không abstraction không yêu cầu, không dependency mới, không boilerplate. Deletion over addition. Mark simplification với ponytail: comment và ceiling.
