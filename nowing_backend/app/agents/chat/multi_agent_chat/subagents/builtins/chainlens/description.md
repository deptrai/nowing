ChainLens Research specialist: performs deep, multi-source web research by dispatching a query to an external ChainLens Research instance. It crawls and synthesizes many pages concurrently, returning a cited answer plus the grounding sources. Use it for literature reviews, due diligence, competitive landscape, complex factual questions, and any ask that benefits from reading dozens of sources and distilling a comprehensive answer. Not for simple real-time lookups (use Google Search), reading one known URL (use web crawling), platform-native conversations (use Reddit/YouTube/TikTok), or Google Maps places.
Triggers include "research X in depth", "deep dive into X", "compare X and Y thoroughly", "what does the literature/web say about X", "comprehensive overview of X", "investigate X", and any request where breadth and synthesis across many sources matter more than a single top-result snippet.
This specialist is slower and more expensive than a plain web search; reserve it for questions that genuinely need broad source coverage and synthesis.
