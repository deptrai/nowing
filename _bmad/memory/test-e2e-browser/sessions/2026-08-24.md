## Bugs found & fixes applied

### Fixed
1. **Public host route was not registered** — `host_web_app` in `nowing_backend/app/routes/web_builder_routes.py` had no `@host_router.get(...)` decorator after the 27.1a patch sweep, so `*.apps.nowing.net` requests 404'd.
   - Fix: added `@host_router.get("/", response_class=HTMLResponse)`.
   - Verified: curl with `--resolve` now returns 200 and the correct `index.html`.
2. **Preview renderer used Babel v8 automatic JSX runtime** — generated `import { jsx } from "react/jsx-runtime"` in the browser, which fails because the module cannot be resolved in a `<script>` tag.
   - Fix: switched to explicit `Babel.transform` with classic runtime and dynamic `MainComponent` discovery.
   - `tests/unit/services/web_builder` and `tests/integration/routes/test_web_builder_routes.py` still pass.

### Fixed (this session)
3. **Preview CDN icon mismatch** — `https://unpkg.com/lucide@latest` loads the vanilla `lucide` UMD whose exports are icon data objects, not React components. Babel transforms the page, but `<Zap />`, `<ArrowRight />`, etc. rendered as objects and React threw `error #130`.
   - Fix: the preview renderer now detects uppercase identifiers used in source that match `lucide[name]` data arrays and installs a small React SVG wrapper for each, so `<Zap />` etc. render correctly. The `MainComponent` discovery now also skips functions tagged with `__wbIcon` so an icon named `Home` is never selected as the app root.
   - Verified: full preview screenshot shows hero, features, pricing, testimonials, and footer with all lucide icons.
4. **Chat tool UI not rendered** — the `build_web_app` tool result used the default emission handler, which only emitted `{"status":"completed","result_length":...}`; the `GenerateWebAppToolUI` could not render because it never received `app_id`, `name`, `preview_url`, etc.
   - Fix: registered `build_web_app` as a deliverable tool and added `deliverables/build_web_app/emission.py` so the full `WebAppBuildOutput` dict is emitted as the tool card payload.
   - Verified: the chat stream now displays the `GenerateWebAppToolUI` card with app name, slug, "Generated" badge, "Open Editor" and "Publish" CTAs, and the publish action successfully produced a live public URL.
