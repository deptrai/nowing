## Defect found + fixed during live demo

### 1. `POST /workspaces/{workspace_id}/sequences` returned 500
- `app/routes/sequence_routes.py` gọi `set_request_tenant_context(session, auth_ctx, workspace_id)` — sai thứ tự positional args, khiến `workspace_id` (int) được truyền vào `client_id` và gây lỗi `expected str, got int` trong `set_config('app.current_client_id', ...)`.
- Sau khi sửa thành keyword `set_request_tenant_context(session, workspace_id=workspace_id)`, lỗi tiếp theo là `SequenceDetailRead.model_validate(sequence)` bị `MissingGreenlet` vì relationship `steps` chưa được eager load.

### 2. `GET/PUT /workspaces/{workspace_id}/sequences/{sequence_id}` cũng dễ gặp `MissingGreenlet`
- Các route detail/update dùng `session.refresh(sequence)` hoặc query riêng `SequenceStep` nhưng vẫn `model_validate(sequence)` trên object chưa load `steps`.

### Fixes
- `app/canonical/tenant_context.py`: chuyển tất cả GUC values (`client_id`, `agent_id`, `run_id`, `user_id`) sang `str(...)` defensively, giống `workspace_id` / `memory_id`.
- `app/routes/sequence_routes.py`:
  - Sửa toàn bộ 11 lời gọi `set_request_tenant_context(session, auth_ctx, workspace_id)` thành `set_request_tenant_context(session, workspace_id=workspace_id)`.
  - Thêm `from sqlalchemy.orm import selectinload`.
  - `create_sequence`: sau `commit`, re-query `Sequence` với `selectinload(Sequence.steps)` rồi mới `model_validate`.
  - `get_sequence` và `update_sequence`: query với `selectinload(Sequence.steps)` và trả về `SequenceDetailRead.model_validate(sequence)` trực tiếp, bỏ các đoạn query steps riêng lẻ.
- `tests/integration/routes/test_sequence_routes.py`:
  - Cập nhật mock `mock_db_session` để trả về object `Sequence` thật với `steps=[SequenceStep(...)]`.
  - Cập nhật các assertion `mock_tenant.assert_awaited_once_with(mock_db_session, mock_auth, workspace_id)` thành `mock_tenant.assert_awaited_once_with(mock_db_session, workspace_id=workspace_id)`.
