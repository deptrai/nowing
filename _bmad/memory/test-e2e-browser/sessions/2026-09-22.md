## Environment discoveries (IMPORTANT — docs are stale)

- **Real dev DB is host Postgres :5432**, not docker :5434. `.env` `DATABASE_URL` points to 5432 and wins over the docker deps DB. Docker `nowing-deps-db-1` (5434) exists but holds stale data (40 token_usage rows vs 174 on 5432). Data written to the wrong DB simply never shows in the app — silent mismatch, hard to notice.
- **Backend port is :4445** — `nowing_web/.env.local` points there. AGENTS.md "backend on :8000" is outdated.
- **Alembic dead revision:** `bcf2ac4cf89d` (merge_235_and_4c04) was deleted by cleanup commits `fe12a11ed`/`404065b54`; any DB stamped with it makes `alembic upgrade`/`stamp` fail with "Can't locate revision". Workaround: `update alembic_version set version_num='239'` directly via SQL (project uses numeric revision ids; head = 239).

- `nowing-deps-redis-1` exists but never runs — `redis-68c` (another container) already serves :6380 and satisfies REDIS_URL.
